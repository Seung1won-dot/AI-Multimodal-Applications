# AI 활용 멀티모달 & MCP PJ1 시즌1

파이썬 기초부터 데이터 분석, 머신러닝/딥러닝, 멀티모달 AI, LangGraph 에이전트까지 단계별로 실습한 Jupyter 노트북 모음입니다.

- **언어**: Python 3
- **환경**: Google Colab, Jupyter Notebook
- **구성**: 5개 단계별 폴더, 각 폴더에 상세 `README.md` 포함

## 소개

AI와 데이터 사이언스의 핵심 분야를 단계별로 학습하는 종합 과정입니다.
